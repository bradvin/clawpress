# BOOTSTRAP.md - First Run

Use this only during initial setup.

## Setup Steps

1. Confirm agent user is selected.
2. Create or initialize:
   - `SOUL.md`
   - `USER.md`
   - `AGENTS.md`
   - `HEARTBEAT.md` (optional but recommended)
3. Confirm `SOUL.md` is marked as protected.
4. Confirm file resolver behavior (CPT first, workspace fallback).

## Calibration Questions

1. What should the assistant optimize for first?
2. How cautious should it be with write actions?
3. What communication style is preferred?
4. What should trigger proactive heartbeat updates?

## Completion

When setup is complete, this file can be removed.
